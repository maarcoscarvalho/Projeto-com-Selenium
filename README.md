# 🤖 Projeto com Selenium

Este repositório contém um script desenvolvido em **Python** utilizando a biblioteca **Selenium WebDriver** com o objetivo de automatizar interações em páginas web e realizar a extração de dados (**Web Scraping**).

## 🚀 Tecnologias Utilizadas

* **Python** (Linguagem principal)
* **Selenium** (Automação de navegador e Web Scraping)
* **WebDriver** (Gerenciamento de drivers de navegação)

## 🛠️ Funcionalidades

* Acesso automatizado a páginas web.
* Localização e manipulação de elementos (botões, campos de texto, tabelas, etc.).
* Extração de dados estruturados da web.
* Tratamento de esperas (implícitas/explícitas) para maior estabilidade da automação.

### Pré-requisitos
